# Reconstruction

## Entry point

```text
recon/recon_wave_tse_from_twix_nifti.py
```

The command reconstructs one TSE scan generated by `seq/tse_2d_wave_mb1.m` or
`seq/tse_2d_wave_mb2v_v3.m`. Its calibration is either the 3D FLASH
calibration appended to the TSE in the same file (the default of both
generators) or a separate mixed FLASH calibration generated by
`seq/gre_mixed_dim_mb2_calibration.m` in the same session. Run it from the
repository root inside the Python environment of the README:

```bash
python recon/recon_wave_tse_from_twix_nifti.py --help
```

## Inputs

| Argument | File |
|---|---|
| `--tse-twix` | TSE TWIX `.dat` |
| `--tse-seq` | TSE `.seq` |
| `--tse-peorder` | TSE `*_PEorder.mat`; default `<seq stem>_PEorder.mat` beside the `.seq`, in its `metadata/` folder, one level up or in `../metadata/`; exactly one must exist |
| `--calibration-twix` | separate mixed calibration TWIX `.dat`; omit it to use the appended calibration |
| `--calibration-seq` | separate calibration `.seq`; given together with `--calibration-twix` |
| `--calibration-labels` | separate calibration `*_geometry_labels.mat`; default `<seq stem>_geometry_labels.mat` beside the `.seq` |

Without `--calibration-twix` the TSE file must carry the appended calibration
(`isAppendCalibration` in its sidecar). With `--calibration-twix`, the
separate calibration is used, also for a TSE that carries an appended one;
the TSE ADCs are then read alone. This is how the two coil-map methods are
compared on one TSE scan.

Use the exact `.seq` and sidecar files exported for the acquisition. The TWIX
header records the sequence file name, and the sequence signatures recorded in
the sidecars must match the `.seq` files.

## Outputs

Two folders receive the subfolders `arrays/`, `cache/`, `nifti/`,
`figures/`, `reports/` and `logs/`: `--output-dir` for the TSE scan and
`--calibration-dir` for its calibration. The calibration folder of a separate
calibration is passed explicitly and can be shared by every TSE scan of that
session. For an appended calibration it defaults to
`<output-dir>/calibration`.

The calibration folder holds:

| File | Content |
|---|---|
| `cache/calibration_encoding.npz` | Wave minus no-Wave trajectory per readout sample (`delta_y`, `delta_z`) and the CSM readout `csm_kx` [1/m] |
| `cache/noise_whitener.npy`, `cache/noise_covariance.npz` | NOISE-scan whitener (coil, coil) and covariance |
| `cache/global_coil_basis.npy` | whitened PCA basis (coil, virtual coil) |
| `cache/csm_slice_XX.npy` | unit-RSS ESPIRiT maps (virtual coil, Nx, Ny) of physical slice XX, from the direct slice or from the 3D ACS |
| `cache/wave_coefficients_<tag>.npz` | Wave PSF coefficients `a`, `b`, `c` per readout sample [rad]; `<tag>` names the fit settings |
| `arrays/csm_diagnostics_XX.npz`, `arrays/wave_projection_diagnostics.npz` | ESPIRiT eigenvalues and calibration RSS; projection phases, masks and coherence |
| `reports/` | input manifest, noise model, coil compression, Fourier-z direction test (separate calibration) or ACS z-orientation test (`calibration_acs_vs_z_projection.json`) and 3D-ACS map settings (`csm_acs3d.json`, appended calibration), Wave projection support and fit validation |
| `figures/wave_coefficient_fit_<tag>.png` | calibration coefficients and fitted Wave curves |

`--output-dir` holds the products of one TSE scan:

| File | Content |
|---|---|
| `cache/encoding.npz` | slice phase (group, band, Ny), sampling masks (group, Ny), raw SLI to group mapping, physical pairs |
| `reports/acquisition_audit.json` | every audited contract value, mapping method and trajectory error |
| `arrays/lambda0_group_XX.npy`, `reports/lambda0_group_XX.json` | group checkpoint (band, Nx, Ny) and its solver report and digest |
| `arrays/lambda0_complex_physical_slices.npy` | complex volume (Nx, Ny, physical slice), physical slice order of the sidecar |
| `nifti/lambda0_magnitude.nii.gz`, `nifti/lambda0_phase.nii.gz` | scanner-geometry NIfTI |
| `reports/lambda0_nifti_geometry.json`, `reports/lambda0_completed.json` | affine, axis codes and readback; final summary |
| `figures/lambda0_all_slices.png` | magnitude montage with physical aspect |
| `logs/run_<time>.log` | progress log of each run |

With `--l1-threshold-multiple` (see
[L1-wavelet regularization](#l1-wavelet-regularization-optional-mb2)), the
same folder also receives:

| File | Content |
|---|---|
| `cache/l1_noise_profile.npz`, `reports/l1_noise_profile.json`, `figures/l1_noise_profile.png` | readout noise-variance profile of the scan relative to the far readout margins, its uncorrected estimate and the noise fraction left by the lambda-0 fit |
| `reports/l1_noise_null_group_XX.json` | far-margin covariance summary, lambda-0 noise RMS, mean normal diagonal and Lipschitz constant of a group |
| `arrays/<tag>_group_XX.npy`, `reports/<tag>_group_XX.json` | L1 group checkpoint (band, Nx, Ny) and its weights, FISTA report and digest |
| `arrays/<tag>_complex_physical_slices.npy`, `nifti/<tag>_magnitude.nii.gz`, `nifti/<tag>_phase.nii.gz`, `figures/<tag>_all_slices.png` | L1 volume and its export |
| `reports/<tag>_settings.json`, `reports/<tag>_nifti_geometry.json`, `reports/<tag>_completed.json` | L1 settings, geometry and final summary |

`<tag>` names the L1 setting: `l1c0p5` for C = 0.5, with `_lev<n>`, `_it<n>`
or `_tol<t>` appended for FISTA settings other than the defaults. Results of
several settings can share one folder; they reuse the lambda-0 solution, the
noise profile and the noise-only solves.

Nothing is overwritten. A rerun with the same inputs and settings resumes from
the saved caches and checkpoints. A folder whose input manifest records other
inputs or settings is rejected; use a new folder instead.

## Stages

`--stage audit`, `--stage calibration` or `--stage recon` (default) selects
the last stage; each stage runs the previous ones.

### Audit

Separate calibration:

- sequence signature against the sidecar; compact labels: unique sequential
  LIN, REF routing as in the sidecar, zero SLC/PAR/SET/ECO;
- Wave trajectory deltas identical on every calibration line (0.02/m);
- CSM lines on the centered physical ky grid with one readout trajectory for
  all slices (0.02/m);
- direct-slice versus Fourier-z receive profiles: the negative convention must
  reach a median correlation of at least 0.95 and exceed the positive one by
  0.2.

Appended calibration:

- the stated number of REF readouts directly after the TSE ADCs, with the
  compact LIN 0...N-1 and zero SLC/PAR/SET/ECO, and the refscan stream
  holding every LIN once;
- Wave trajectory deltas identical on every projection line (0.02/m);
- ACS lines on the centered physical ky grid and the stated kz moments, with
  one readout trajectory (0.02/m);
- z orientation (MB2): at ky = 0 and the center kx sample, the ACS planes at
  the slice centers are compared with the no-Wave z projection, low-passed to
  the ACS kz extent and read with the established negative Fourier-z
  convention; the stated orientation must reach a median receive-vector
  correlation of at least 0.9 and exceed the reversed one by 0.1. For MB1,
  the TSE slices test the z orientation (see Reconstruction).

TSE:

- recorded sequence name, readout length, FOV (equal to the calibration) and a
  transverse or transverse-dominant oblique slice normal; receive-element
  identities, stack center, slice normal and in-plane rotation equal to the
  calibration;
- sidecar slice positions, thickness, in-plane FOV and SMS pairing equal to
  the calibration; Wave cycles, amplitude and polarity equal to the
  calibration for Wave scans;
- raw ADC chronology equal to the sequence ADC order, or to an exact prefix of
  it when `--allow-missing-final-adcs N` admits a file that ended early; the
  missing lines become unsampled entries of their group mask;
- sequence SLC labels map one-to-one onto scanner SLI counters, and every SLC
  follows the sidecar LIN order;
- physical group of every excitation: carrier frequency divided by the slice
  gradient within 3 um when the excitations use a scalar carrier; otherwise
  (v3 MB2, whose RF waveforms encode the group offset) the sidecar
  `groupBySlc` mapping, accepted only when demodulating every excitation at
  its group center recovers one RF envelope and the opposite sign fails;
- scanner MDH slice offsets equal to the mapped group centers along the slice
  normal, up to one global sign, which is recorded (-1 for the Prisma MB1 conventional-sinc scan, +1 for
  the Prisma MB2 scans of 2026-10-15);
- sampled kx, ky and kz equal to the calibration-derived trajectory within
  0.02/m (kx, ky) and 0.01/FOV (kz, after the CAIPI blips);
- MB1 may use the y-sine Wave alone; MB2 Wave scans need both Wave axes.

The slice phase of band `b` at line `ky` is
`exp(+i*2*pi*(2*A(ky) - kz_base(ky))*z_b - i*adc_phase)`, with the CAIPI area
`A` from the sidecar and the band position `z_b` from the sidecar slice
positions.

### Calibration

- Whitener from the calibration NOISE scan; one PCA basis (default 20
  virtual coils, `--virtual-coils`) from every third readout sample of all
  direct FLASH slices (separate calibration) or all 3D ACS readouts (appended
  calibration) after whitening. The same basis compresses the CSM data and
  every TSE group.
- Separate calibration: ESPIRiT per physical slice, calibration width 24,
  crop 0, unit coil RSS; slices are never interpolated or Fourier transformed
  along z. SigPy's CPU ESPIRiT runs on one thread (about 39 min for a
  920 x 920 slice); `--csm-workers N` estimates N slices in parallel CPU
  processes, and `--csm-device 0` runs it on GPU 0.
- Appended calibration: the ACS readout is transformed to image space and
  cropped to the native FOV; at every readout position ESPIRiT (calibration
  width 24, crop 0) runs in (ky, kz) on the z grid whose planes are the slice
  centers, and the maps of those planes are saved in the same per-slice
  files. A 440-sample readout takes several seconds per position on one CPU
  thread; `--csm-workers N` runs chunks of readout positions in N processes.
- Wave PSF for Wave scans: wrapped-phase line fits of the y and z
  projections with noise, coherence and support gates, then sine-line models
  of `a`, `b` and `c` per readout sample. For the y-sine MB1 Wave only the y
  projections are fitted (`b = 0`, `c` the y constant; tag suffix `_y`). The
  z fit uses only the positions inside the slice stack: an object longer than
  the 160 mm z FOV, such as a phantom, aliases into the outer z rows with both
  Wave phases, and those rows carry no valid phase. By default the coefficient processor
  selects an automatic stable interval, and the supported phase residual must
  not exceed 0.25 rad. When it rejects the calibration,
  `--psf-fit-range START STOP` fits a reviewed interval `[START, STOP)` of
  readout samples instead; the samples outside it are then held out, and the
  held-out coefficient error and the phase residual inside and outside must
  not exceed 0.25 rad. `--psf-low-amplitude-c-fallback` permits the
  frequency-locked fit of a constant phase too small for the free fit. Fits
  with different settings are stored under different tags.

The Wave PSF of band `b` is evaluated with `z = -z_b`, the convention that the
Fourier-z test establishes.

### Reconstruction

- MB1: a complete no-Wave grid gives each slice as the exact least-squares
  coil combination; with the y-sine Wave or an undersampled grid each slice is
  solved with lambda-0 CG-SENSE through the one-band Wave operator, after the
  operator tests below. Before the slices are solved, five slices are compared
  with the stated and with the slice-reversed FLASH maps: on a complete grid by
  coil-vector projection (after an exact Wave-PSF deconvolution for Wave data),
  on an undersampled grid by the data residual of a CG solve with each map. The
  stated mapping must give the lower residual on all five and a residual below
  0.4 and below half the reversed one on the second and fourth.
- MB2: lambda-0 CG-SENSE per SMS group (tolerance 1e-6, at most 800
  iterations, `--tolerance`, `--max-iterations`) with the MB2 Wave operator,
  after a real-grid adjoint test (relative error at most 1e-5) and a synthetic
  recovery test (data residual at most 1e-3) on the first group. Wave scans
  need both the y-sine and the z-cosine Wave.

Every group report records the solver information and the relative data
residual. `--device cuda` runs the TSE solver on a GPU and `--csm-device 0`
runs ESPIRiT on GPU 0 (needs CuPy); both default to the CPU.

### L1-wavelet regularization (optional, MB2)

`--l1-threshold-multiple C` adds a second solution of every MB2 group after
lambda 0. FISTA minimizes

```text
0.5 * ||W (A x - y)||^2 + sum_b lambda_b * ||Psi x_b||_1
```

with the far-margin coil whitener `W` of the group (below), the MB2 Wave
operator `A`, and an orthonormal periodized db4 wavelet transform `Psi` with 3
levels (`--l1-wavelet-levels`) applied to each band image separately on the
native readout rows; the coarsest approximation band is not penalized. FISTA
starts from the lambda-0 solution with the step 1/L, where L is 1.05 times a
30-iteration power estimate of the largest eigenvalue of the whitened normal
operator. It stops after 300 iterations (`--l1-max-iterations`) or when the
relative image change falls below 1e-4 (`--l1-tolerance`); a group that uses
the full budget is kept and logged.

The weight of band `b` is

```text
lambda_b = C * sigma_b * d_b
```

where, inside the region in which the FLASH calibration RSS of the band's
slice exceeds 10% of its peak,

- `sigma_b` is the RMS of the whitened lambda-0 reconstruction of noise alone,
  drawn from the noise model below (seed 20261025 + group), and
- `d_b` is the mean diagonal of the whitened normal operator, the sampled
  line fraction times the mean of `sum_c |W S_c|^2`.

The noise model is measured on the TSE data:

- Coil covariance: per group, on the far readout margins (the outer 20% of
  the oversampled readout at each end) of all sampled lines, which receive no
  signal. A group stops if its lambda-0 prediction carries more than 1% of the
  data power there, i.e. if the Wave spread reaches the margins.
- Readout profile: the noise variance at every readout sample relative to the
  far margins, which the receiver filter makes about twice as large inside the
  FOV on the TerraX scans. It is estimated once per scan on the central group
  (number of groups // 2): the whitened lambda-0 residual power of the PE lines
  in the outer 30% of the grid, which hold noise only, divided by the residual
  power that the same lambda-0 fit leaves of synthetic noise with the margin
  covariance and a flat profile (seed 20261026). The division removes the noise
  share that the fit absorbs inside the FOV; on the TerraX R2x4 scan the fit
  leaves 66% of the noise there. At least 8 outer lines must be sampled, and
  the fit must leave at least 20% of the noise everywhere in the FOV.

C = 0.5 was chosen by visual review on the TerraX 2026-10-25 R2x4 scan
(MB2 x Ry4, 0.24 mm, 7 T). That research reconstruction took the readout
profile from a fully sampled 2026-10-19 scan without removing the share
absorbed by its fit; on group 12 of the R2x4 scan the per-scan profile gives
5% larger weights. C has not been reviewed on other protocols. The 220 PE
lines of the published 440 x 220 protocol allow at most 2 wavelet levels
(`--l1-wavelet-levels 2`).

### NIfTI export

The centered-IFFT PE axis runs opposite the header PE axis and the direct
calibration slices run opposite Fourier-z, so the volume is flipped along PE
and slice before the TWIX-derived affine is applied (`twix_inplane_rot_sign
-1`, stack center from the MDH slice positions). Magnitude and phase are
written as float32 NIfTI and read back; values and affine must match exactly.

## Example: Prisma 2026-10-15 MB1 conventional-sinc regression

The saved result of the research pipeline is in
`20261015_prisma_tse/tse_mb1_conv_sinc_rf/` (calibration products in
`tse_calibration/`). Choose two new folders, then:

```bash
DATA=/path/to/20261015_prisma_tse
SEQ=/path/to/scan_protocols/20261015_prisma
OUT=/path/to/new/regression/folder

python recon/recon_wave_tse_from_twix_nifti.py \
  --calibration-twix $DATA/meas_MID00086_FID48497_pulseq_calib.dat \
  --calibration-seq $SEQ/tse_product_control/gre_mixed_dim_mb2_calib_waveYZ3dproj_csm2d_Ncyc20_440x220x80_FOV220_Nacs32_os3_prisma.seq \
  --tse-twix $DATA/meas_MID00089_FID48500_pulseq_tse_mb1_conv_sinc_rf.dat \
  --tse-seq $SEQ/tse_product_control_mb1/v151/tse_mb1_convEx2p5R3p1_Ncyc20_TRA_440x220x50_FOV220_Ry1_os3_ETL17_TE15p29_TR13666_skyra.seq \
  --calibration-dir $OUT/calibration \
  --output-dir $OUT/tse_mb1_conv_sinc_rf

python evaluation/compare_reconstructions.py \
  --candidate $OUT/tse_mb1_conv_sinc_rf/arrays/lambda0_complex_physical_slices.npy \
  --reference $DATA/tse_mb1_conv_sinc_rf/arrays/complex_physical_slices.npy \
  --nifti $OUT/tse_mb1_conv_sinc_rf/nifti/lambda0_magnitude.nii.gz \
          $DATA/tse_mb1_conv_sinc_rf/nifti/tse_mb1_conv_sinc_rf_scanner_geometry_magnitude.nii.gz
```

The audit stage of this command and of the Prisma MB2 R1 Wave scan reproduces
the saved encoding tables of the research pipeline bit for bit.

## Example: TerraX 2026-10-25 R2x4 L1-wavelet comparison

The research result of this MB2 x Ry4 scan, including its lambda-0 and L1
(C = 0.5) volumes, is in `20261025_terrax/tse_240um_R2x4_wave/`. The TSE file
ends one ADC early, and the Wave PSF uses the reviewed readout interval of the
0.24 mm calibration. Choose a new folder, then:

```bash
DATA=/path/to/20261025_terrax
SEQ=/path/to/scan_protocols/20261019_terrax/tse_product_control_mb2_Ncyc20_0p24mm_TE77
REF=/path/to/20261025_terrax/tse_240um_R2x4_wave
OUT=/path/to/new/comparison/folder

python recon/recon_wave_tse_from_twix_nifti.py \
  --calibration-twix $DATA/meas_MID00150_FID74171_pulseq_gre_calib.dat \
  --calibration-seq $SEQ/gre_mixed_dim_mb2_calib_waveYZ3dproj_csm2d_Ncyc20_920x920x80_FOV220p8_Nacs32_os3_TerraX.seq \
  --tse-twix $DATA/meas_MID00152_FID74173_pulseq_tse_R2x4_wave.dat \
  --tse-seq $SEQ/v151/tse_m2prodctl_B15_cF8_wYZ_N20_TRA_920x920x50_F220p8_R4_os3_E13_ES15p60_TE78_TR20000_TerraX.seq \
  --calibration-dir $OUT/calibration \
  --output-dir $OUT/tse_r2x4 \
  --psf-fit-range 1155 1605 --psf-low-amplitude-c-fallback --allow-missing-final-adcs 1 \
  --csm-workers 12 --threads 8 --l1-threshold-multiple 0.5

python evaluation/compare_reconstructions.py \
  --candidate $OUT/tse_r2x4/arrays/lambda0_complex_physical_slices.npy \
  --reference $REF/arrays/lambda0_complex_physical_slices.npy \
  --nifti $OUT/tse_r2x4/nifti/lambda0_magnitude.nii.gz \
          $REF/nifti/r2x4_240um_lambda0_scanner_geometry_magnitude.nii.gz
python evaluation/compare_reconstructions.py --rtol 0.02 \
  --candidate $OUT/tse_r2x4/arrays/l1c0p5_complex_physical_slices.npy \
  --reference $REF/arrays/l1c0p5_complex_physical_slices.npy \
  --nifti $OUT/tse_r2x4/nifti/l1c0p5_magnitude.nii.gz \
          $REF/nifti/r2x4_240um_l1c0p5_scanner_geometry_magnitude.nii.gz
```

The audit stage reproduces the saved encoding tables and Fourier-z test of the
research pipeline bit for bit. With the research noise model (its readout
margins and reference profile), the per-group functions of this command
reproduce the saved noise RMS, normal diagonal and weights of group 12
exactly, and its L1 image to a relative L2 difference of 1e-6. The lambda-0
volume is expected to match. The L1 volume differs because the per-scan noise
profile raises the weights by 5%: by 0.5% and 0.8% (relative L2) in the two
bands of group 12.

## Example: integrated scan and coil-map comparison

A TSE exported with its appended calibration needs only the TSE inputs:

```bash
DATA=/path/to/session
SEQ=/path/to/out_path
OUT=/path/to/new/output/folder

python recon/recon_wave_tse_from_twix_nifti.py \
  --tse-twix $DATA/meas_..._tse_..._cal_skyra.dat \
  --tse-seq $SEQ/v151/tse_m2b7v1_B15_cF2_wYZ_N20_TRA_440x220x50_F220_R1_os3_E17_ES15p29_TE107_TR15000_cal_skyra.seq \
  --csm-workers 8 \
  --output-dir $OUT/tse_3d_acs
```

The calibration products are written to `$OUT/tse_3d_acs/calibration/`. To
compare the 3D-ACS coil maps with the direct-slice maps of a mixed
calibration acquired in the same session, reconstruct the same TSE once more
with the separate calibration and compare the two volumes:

```bash
python recon/recon_wave_tse_from_twix_nifti.py \
  --calibration-twix $DATA/meas_..._pulseq_calib.dat \
  --calibration-seq $SEQ/gre_mixed_dim_mb2_calib_waveYZ3dproj_csm2d_Ncyc20_440x220x80_FOV220_Nacs32_os3_skyra.seq \
  --tse-twix $DATA/meas_..._tse_..._cal_skyra.dat \
  --tse-seq $SEQ/v151/tse_m2b7v1_..._cal_skyra.seq \
  --calibration-dir $OUT/mixed_calibration \
  --output-dir $OUT/tse_mixed_csm

python evaluation/compare_reconstructions.py \
  --nifti $OUT/tse_3d_acs/nifti/lambda0_magnitude.nii.gz \
          $OUT/tse_mixed_csm/nifti/lambda0_magnitude.nii.gz
```

Compare magnitudes: ESPIRiT maps carry an arbitrary phase per voxel, so the
complex volumes of the two calibrations differ by that phase. The comparison
reports the relative L2 difference; its pass threshold (`--rtol`, default
1e-5) is meant for regressions, not for two calibration methods. Both runs
use their own calibration's noise whitener, coil basis and Wave PSF; the
group reports (`reports/lambda0_group_XX.json`) record the relative data
residual of each solution.

## Validation status and limitations

- Regression target: the Prisma 2026-10-15 MB1 conventional-sinc scan
  (MID89) with its calibration (MID86), compared with the saved result of
  the research pipeline as shown above. The MB2 path has passed the audit on
  the Prisma MB2 product-control scans; its full regression is pending.
- The v3 MB2 sequence, the appended 3D FLASH calibration and the MB1 Wave
  reconstruction have been tested on one phantom session (2026-11-05): MB2
  R1 to R4 and MB1 R1 and R2, each reconstructed with its appended
  calibration and with a separate mixed calibration. The scanner accepted
  the REF readouts of the 2D multi-slice protocol, the refscan stream held
  every calibration readout, and the waveform-encoded slice mapping passed
  with the RF sign convention measured on the Prisma 2026-10-15
  product-control MB1 data. Against the mixed calibration, the data residual
  matched within 1%, and at R > 1 CG needed fewer iterations and the
  background noise was lower (1.57 times at MB2 R4). No in vivo scan has been
  reconstructed with the appended calibration. The ACS z convention is the
  negative Fourier-z convention that the mixed calibrations established; the
  ACS-versus-z-projection test re-checks it on every MB2 scan and the
  slice-reversal test on every MB1 scan.
- Transverse and transverse-dominant oblique prescriptions only. The
  reconstruction runs in the logical frame; the NIfTI affine of an oblique
  stack follows the header normal and has not been compared with DICOM.
- L1-wavelet regularization: the per-scan noise profile is validated on
  synthetic data and on group 12 of the TerraX 2026-10-25 R2x4 scan; the
  full-volume comparison above is pending. C = 0.5 has been reviewed on that
  scan only.
